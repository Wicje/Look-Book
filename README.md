# 📖 Lookbook — Visual Catalog & Design Showcase

> A modern Next.js visual catalog and design showcase manager for archiving interface patterns, visual references, and brand asset libraries.

---

## 🚀 Installation & Launch

Install `lookbook` launcher shortcut via Josephan installer:

```bash
curl -fsSL install.josephan.dev | bash
```

Or run locally:

```bash
npm install
npm run dev
```
